# Vakha Album Designer

Профессиональный offline-first редактор выпускных альбомов. Проект создаётся как самостоятельное локальное приложение без CRM, backend, авторизации, аналитики и отправки пользовательских фотографий в интернет.

## Текущий статус

Завершены этапы 1–10: фундамент приложения, редактор холста, страницы/слои, текст,
изображения, шаблоны, участники, персонализация, проверка/экспорт и рабочие материалы:

- React, TypeScript и Vite;
- маршрутизация разделов;
- тёмная дизайн-система по утверждённым интерфейсным коллажам;
- App shell и Editor shell;
- IndexedDB через Dexie, schema v1;
- Zustand stores;
- PWA app shell и update prompt;
- ESLint, Prettier, Vitest, Testing Library и Playwright;
- Fabric.js за изолированным адаптером;
- логические координаты в миллиметрах и отдельный UI zoom;
- интерактивный двухстраничный разворот из страниц 20 × 20 см;
- выделение, множественное выделение, перемещение, масштабирование и поворот;
- pan инструментом «Рука» или `Space + drag`;
- zoom колесом, кнопками и `Cmd/Ctrl + 0`;
- сетка, безопасные зоны и привязка к шагу 5 мм;
- транзакционный Undo/Redo;
- нормализованное сохранение canvas-сцены в Dexie и восстановление после reload;
- независимые страницы, связанные двухстраничные развороты и миграция сцен этапа 2;
- создание, дублирование, удаление и изменение порядка страниц/разворотов;
- миниатюры страниц с упрощённой геометрией видимых слоёв;
- панель слоёв с синхронизацией выбора с холстом;
- rename, visibility, lock, duplicate, delete и изменение порядка слоёв;
- группы, разгруппировка и вложенность до трёх уровней;
- текстовые слои и редактирование двойным кликом прямо на холсте;
- типографика, регистр, интервалы, выравнивание, обводка и тень;
- фиксированные и автоматические текстовые области;
- предупреждение, обрезка, перенос и автоуменьшение текста с минимальным размером;
- локальная загрузка TTF, OTF, WOFF и WOFF2 с проверкой сигнатуры;
- хранение пользовательских шрифтов в IndexedDB и повторная регистрация через FontFace;
- поиск, избранные, недавно использованные и удаление пользовательских шрифтов;
- явное предупреждение об отсутствующем шрифте без потери исходного названия.
- локальная загрузка JPEG, PNG, WebP и проверенного SVG;
- массовая загрузка, drag-and-drop и вставка изображений из буфера обмена;
- неизменяемые оригиналы и производные WebP-миниатюры в IndexedDB;
- фоторамки rectangle, rounded, circle, oval, polygon и пользовательская SVG-маска;
- Cover/Contain, фокусная точка, масштаб кадра и отражение;
- параметрические цветовые эффекты, рамка, прозрачность и тень;
- эффективный DPI и предупреждение о низком качестве;
- восстановление crop и эффектов после перезагрузки без изменения оригинала;
- ограниченная загрузка в память только используемых ресурсов и отзыв Object URL.
- каталог системных, пользовательских и подготовленных Codex шаблонов с фильтрами, избранным и предпросмотром;
- три полностью редактируемых системных направления: редакционное, школьное и кинематографическое;
- независимое клонирование страниц, разворотов, слоёв и локальных ресурсов в новый проект;
- сохранение текущей страницы или всего проекта как пользовательского шаблона;
- версионированный ZIP-пакет `.vstemplate` с Zod-проверкой и защитой от небезопасных путей;
- декларативные `pageType`, `repeatFor` и привязки слоёв для последующей персонализации;
- импорт `.vsclass`, список участников, статусы, фото и bulk-операции;
- разрешение bindings в персональные страницы и точечные participant overrides;
- проверка проекта с уровнями error/warning/info;
- локальный экспорт PDF, PNG, JPEG и ZIP с выбором DPI, страниц/разворотов и участников;
- редактируемый `.vsalbum` backup/restore;
- референсы, идеи и аннотации с локальным CRUD, фильтрами и привязками к проекту,
  странице, слою или участнику;
- отдельный экспорт аннотаций в JSON/Markdown без попадания рабочих материалов в печатный
  рендер альбома.

## Требования

- Node.js 22.12 или новее;
- npm 11 или совместимая версия.

## Установка и запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес приложения. Начальный маршрут — `/projects`.

## Проверки

```bash
npm run typecheck
npm run lint
npm run test
npm run build
npm run test:e2e
npm run fixtures:generate
npm run profile:large
npm run format:check
```

Дополнительные команды:

```bash
npm run preview
npm run test:watch
npm run format
```

Для первого локального E2E-запуска может потребоваться установка браузера:

```bash
npx playwright install chromium
```

## Маршруты

- `/projects` — проекты;
- `/templates` — каталог шаблонов;
- `/editor/:projectId` — оболочка редактора;
- `/projects/:projectId/import-class` — импорт класса;
- `/projects/:projectId/participants` — участники;
- `/projects/:projectId/references` — референсы;
- `/projects/:projectId/ideas` — идеи;
- `/projects/:projectId/annotations` — аннотации;
- `/projects/:projectId/validation` — проверка;
- `/projects/:projectId/export` — экспорт;
- `/settings` — настройки.

## Локальное хранение и офлайн-режим

Dexie открывает базу `vakha-album-designer` в IndexedDB. PWA Service Worker кэширует только версионированную оболочку приложения и статические ресурсы. Пользовательские данные не дублируются в Cache Storage и не отправляются в сеть.

В настройках можно переключить фиолетовый или синий интерфейсный акцент. Выбор сохраняется в IndexedDB и восстанавливается после перезапуска.
